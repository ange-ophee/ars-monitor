# ARS Monitor

A full-stack web application designed to support the monitoring and evaluation of cocoa farmers and farms against the African Regional Standard (ARS 1000) for sustainable cocoa production.

### Features
- Farmer and farm management
- Compliance monitoring and evaluation
- Dashboard and reporting
- User authentication and role-based access

### Tech Stack
- React
- Node.js
- Express.js
- MongoDB

### Project Type
Final-Year Academic Project | Full-Stack Web Development
